# Python 自動化開發作品集

> 專注於 **Python 自動化、瀏覽器自動化、API 串接、公開資料整理、AI 工作流程與桌面 GUI 開發**。

這個 Repository 整理了我實際開發過的部分自動化程式作品，主要目標是把大量重複、耗時的人工操作，轉換成可重複執行、可管理、可追蹤的自動化流程。

## 🚀 主要開發能力

- Python 桌面程式與 GUI
- Selenium / Playwright 瀏覽器自動化
- REST API 串接與第三方服務整合
- 多執行緒與批次任務處理
- 網站公開資料收集與整理
- TXT / CSV / Excel / SQLite 資料處理
- 自動下載、重新命名與檔案管理
- AI 圖片／影片生成工作流程自動化
- 錯誤重試、日誌、診斷與任務狀態管理

## 📂 作品項目

### 1. AdsPower 環境管理大師
AdsPower Local API 桌面管理工具，可集中讀取與管理瀏覽器環境，包含搜尋、批次更名、群組轉移、開啟／關閉環境、狀態管理與資料匯出等功能。

**技術：** Python、Tkinter、Requests、REST API

### 2. Facebook 搜尋工具箱
以 Playwright 與 AdsPower 為核心的瀏覽器資料整理工具，包含多環境工作流程、搜尋結果整理、條件判斷、日期解析、GUI、進度顯示及錯誤診斷架構。

**技術：** Python、Playwright、AdsPower API、Tkinter、Requests

### 3. Google FLOW 圖片影片自動化工具
將 AI 圖片／影片生成流程自動化，包含瀏覽器接管、提示詞輸入、素材處理、任務執行、生成監控、作品下載與檔案重新命名等流程。

**技術：** Python、Browser Automation、GUI、檔案處理

### 4. 瀏覽器自動化管理系統
模組化瀏覽器工作流程管理系統，將瀏覽器控制、任務執行、錯誤處理、狀態檢查、資料處理等功能拆分為可維護模組。

**技術：** Python、Selenium / Browser Automation、API、模組化架構

### 5. 社群互動自動化系統
以瀏覽器自動化為基礎的工作流程系統，包含任務管理、頁面狀態判斷、互動流程、例外處理與 GUI 操作介面。

**技術：** Python、Browser Automation、GUI、多執行緒

### 6. 菲律賓企業公開資料整理工具
針對企業公開資訊建立的資料整理流程，可將不同來源的公開公司資料進行擷取、清理、去重、格式化與輸出。

**技術：** Python、Web Data Processing、Requests、HTML Parsing、CSV / TXT

## 🧩 開發流程

**需求確認 → 流程拆解 → GUI → 自動化 → API → 資料儲存 → 錯誤處理 → 測試 → 打包與後續修改**

適合處理大量重複人工操作、網站後台工作、資料整理、API 串接、桌面工具與客製化自動化需求。
